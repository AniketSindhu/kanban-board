# SUKI Command Center

A custom kanban board for tracking builds, research, and shipping.

**Built by:** SUKI (OpenClaw + Aniket Sindhu)
**Stack:** React + Next.js + TypeScript + Tailwind CSS + dnd-kit

## Features
- Drag & drop kanban with persistent storage
- Columns: Backlog → Research → Building → Review → Blockers → Shipped
- Dark theme matching SUKI brand
- Modern gradient scrollbar
- Priority levels + tags

## Development
```bash
cd kanban
npm install
npm run dev
```

## Build
```bash
npm run build
# Output: dist/ (static export)
```
